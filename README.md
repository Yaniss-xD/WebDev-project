This is my first school project after 1 year off CS.
It's a website that shows you recipes based on vegetables.
My classmate and I thought that it would be cool if we split the recipes based on the seasons.
For example: winter has parsnips, carrots, cabbage... so it only gives recipes based on these veggies (in theory).

There aren't a lot of recipes, and it has some mistakes.
For example, on the recipe page, you should see the image of the recipe, but there is a mistake, and I couldn't fix it.

Here's a description of what each page does (in French):

## Pages du site

- Accueil : présentation du site et accès aux différentes saisons.
- Recettes : affichage de toutes les recettes.
- Détail d’une recette : ingrédients, préparation et photos.
- À propos : présentation du projet + une option pour donner son avis (je ne peux malheureusement pas enregistrer les avis donnés).

Les autres pages font en sorte que l’automatisation des pages fonctionne, par exemple :

- donnees : pour mettre les recettes, leurs images, les ingrédients...
- Saisons (hiver, été, printemps, automne) : pour montrer une liste des légumes de la saison et des recettes pour la saison.
- top : c’est la navigation + le logo.
- footer : juste le copyright.
